# Bright Nights Mapgen Editor

## Features

- Palette import
- Multiple palettes
- Palette inheritance
- Quick test of mapgen in game (press button -> be spawned in game next to your building)
- Implement all mapgen pieces
- Multiple mapgens on same screen (viewports)
- Update mapgen, blueprint autocalc
- Item group editor & tester
- Vehicle placement preview (boundaries around pplacement point)
- Import existing mapgens
- Simpler download/install/setup
- Import from pixels
- Import from excel
- Design simple overmap specials that use the mapgen
